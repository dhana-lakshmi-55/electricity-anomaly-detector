# ⚡ Electricity Anomaly Detector

## 📌 Overview
The Electricity Anomaly Detector is a Machine Learning project that identifies abnormal electricity consumption patterns using historical electricity usage data. It helps detect unusual energy usage and provides insights for efficient power management.

## 🚀 Features
- Detect abnormal electricity consumption
- Data preprocessing and cleaning
- Data visualization
- Machine Learning based anomaly detection
- CSV dataset support

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
